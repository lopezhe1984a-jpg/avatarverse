Preguntas frecuentes

Todo claro antes de empezar

¿Qué es AvatarVerse?

Una plataforma independiente para crear y transformar contenido visual mediante herramientas de IA conectadas a tus propios servicios.

¿Puedo generar imágenes y video?

La interfaz incluye módulos de imagen y video. Para generación real debes conectar un proveedor de modelos o tu backend.

¿Puedo usar mis propias imágenes?

Sí. El estudio permite cargar archivos locales y previsualizarlos.

¿Puedo cambiar los modelos?

Sí. El selector está preparado para integrarse con diferentes endpoints.

¿Es independiente de Dreamerland?

Sí. Esta versión no utiliza scripts, logos, dominios ni dependencias de Dreamerland.
